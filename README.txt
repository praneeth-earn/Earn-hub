EarnHub Phase 1
================
A frontend-only prototype for a commission/rewards website.

Run:
1. Extract the ZIP.
2. Open index.html in a browser.
3. Create an account and test the dashboard.

Included:
- Homepage
- Login
- Signup
- User dashboard
- Demo tasks/referrals/ad rewards
- Responsive mobile design

Important:
This is a UI prototype. It does not contain a real payment gateway, database,
task verification system, or ad network. Those should be added in Phase 2
with appropriate security, privacy, payout and advertising compliance.
